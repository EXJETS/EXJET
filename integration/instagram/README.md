# Instagram presentation handoff

The website currently links directly to the official EXJET Instagram profile in the About, Contact, and footer areas.

Instagram supports embedding individual public posts when embedding is enabled on the account. A true automatically updating latest-post grid requires an approved Meta app, access token management, caching, privacy review, and a server-side refresh process. Do not place a Meta access token in the static site or browser bundle.

Recommended launch approach:

1. Keep the fast, privacy-friendly profile links now.
2. Select one or two evergreen public posts and paste their official embed codes only after EXJET approves the exact posts.
3. Add a server-cached feed later if the visual benefit justifies the third-party scripts and consent requirements.
