# Airport aircraft results
Search matches only US-registered N numbers that match an approved model in the FAA Part 135 snapshot. That snapshot lives on the server and is not a public availability feed. The first leg controls the cards. Home-base matching is exact; the operator's headquarters and nearby airports are not bases. Nationwide floating matching is built but is **off** unless EXJET confirms its aircraft and EXJET_FLOATING_FLEET_ENABLED is explicitly true. An FAA-eligible registration without separately sourced coverage is not shown.

data/charter-faa-approved.json carries [tail, approved model slug, FAA certificate holder, designator] rows derived from the FAA air charter operators workbook. Refresh the FAA snapshot and review ambiguous models before changing the catalog. Do not use the older proprietary research CSV for public results. data/charter-home-bases.json contains tail-specific home bases independently confirmed on public operator pages. EXJET_PUBLISHED_FLEET optionally accepts approved records of the same shape for limited operations use; it must also join to the FAA catalog. At larger scale replace the configuration override with a maintained catalog store and pagination.

The card sends the aircraft preference to the charter desk. It does not promise an aircraft or availability. The card price is a route/cabin estimate, not a tail-specific price. Use only cleared, matching aircraft model photos; missing photos show a neutral aircraft icon. Unknown airport matches can still request a charter quote.
