Cadence and sequencing live in `07-90-day-execution-plan.md` (2–3/week). Every article must include, at minimum: one link to its primary target service/location page, one link to another related article, and the standard "Get a Quote" inline CTA module after the second H2 (per the `journal/[slug]` template spec in the architecture doc).

Word-count guidance: pillar/guide posts (marked ★) run 1,800–2,500 words; standard posts run 1,000–1,500 words. Don't pad — a tight 1,000-word post that fully answers the query outperforms a bloated 2,500-word one that doesn't.
